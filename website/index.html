A few good questions.

Before you
press play.

Does Cinefern include movies?+

Open Cinema includes a curated selection of freely available Blender open films. Connect your Jellyfin server, add a JSON catalog, or install a provider to bring your own media. Cinefern doesn’t include a commercial streaming subscription.

Does my progress sync between devices?+

Cinefern saves watch history and playback progress on your device. You can move library data with import and export. Automatic cross-device cloud sync is not currently included.

What can I watch offline?+

You can download supported progressive HTTP media files. Adaptive HLS and DASH streams, live streams, and DRM-protected media are not available for offline download. On Apple TV, the system may clear cached downloads to free space.

Can I help build Cinefern?+

Absolutely. Explore the source on GitHub, report an issue, improve the documentation, or create a provider with the TypeScript SDK. Cinefern is the modern successor to NWPlay, built with React Native and TypeScript.
